# Company v1 gameplay design options

상태: adopted

The Phase 0.5 baseline adopts 2C, 3C2, 4C, 5C, 6C, 7C, 8C, 9C, 10C, 11C, 12C, 13C, 14C, 15C, and 16C from the original option set. These are no longer pending user decisions.

The adopted design is free sandbox play with light long-term progression; canonical CSA compilation with one confirmation screen; four active rules with free replacement; applicability/scope/override/strength/recency conflict order; immediate current normalization with reinterpreted memory; retained event consequences after deactivation; scene-state progression; soft availability; structured event ledger; lightweight behavior cores; axis-specific persistence; probability only for extreme bold actions; exact-action mandatory scope; lightweight work hooks; and simple player setup with free input.

Relationship is multi-axis (`closeness`, `romance_status`, `current_boundary`, milestones, and summary), not a canonical linear relationship stage. Common-sense response is split into `common_sense_baseline` and `csa_attitudes[csa_id]`. Rule recognition and a character's response remain separate. General NPCs use registered profiles only. A physically possible player action is not made `blocked` merely to control progression.

The authoritative contract is `PHASE_0_5_GAMEPLAY_CONTRACT.md`; recovery, guarded merge, feedback revision, and future save migration are defined by their matching Phase 0.5 contract documents. Soft issues do not regenerate Story or block a valid Commit.
